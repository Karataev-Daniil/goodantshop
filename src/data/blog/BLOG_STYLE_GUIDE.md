# Гайд по стилю постов блога GoodAntShop

Файл-инструкция для агента (и для человека). Прочитать перед тем, как писать или
править пост блога. Эталоны, которым всё должно соответствовать:
`why-ants-are-fascinating.js` (пост 401, «манифест») и `messor-structor.js`
(пост 402, про вид). Оба следуют правилам ниже.

---

## 1. Файл и схема

- Один пост = один файл `src/data/blog/<slug>.js`, `export default { ... }`.
- Зарегистрировать в `src/data/blogPostsData.js`: импорт + добавить в массив
  `blogPosts`. **Порядок в массиве = порядок в блоге**, а `blogPosts[0]` -
  featured-карточка на странице блога (сейчас первым специально стоит старый
  «манифест» 401, не новый пост).
- Картинки подключать **только через** `src/assets/images/library.js`, не прямым
  путём к файлу. Новое фото сначала добавить в `library.js` (импорт + экспорт).
- Поля объекта: `id` (уникальный), `slug`, `category` (`"beginners"` | `"species"`
  и т.п.), `title`, `excerpt`, `seoTitle`, `seoDescription`,
  `cover { src, alt, width: 1200, height: 630 }`, `datePublished`, `dateModified`,
  `author { name: "GoodAntShop", url: "/about" }`, `readingTime` (~7), `content[]`,
  `faq[]`, `relatedProductIds[]`, `relatedPostIds[]`.
- Все тексты - i18n-объекты `{ ru, ro, en }`. Новый пост можно делать **ru-only**
  (`ro`/`en` автоматически показывают `ru` через `getText`). Переводы добавляем
  только по отдельному запросу.
- Вид называем и по-русски, и по-латыни при первом упоминании: «Мессор структор,
  он же Messor structor».

## 2. Словарь блоков `content` (в порядке появления)

- **lead** - вводный абзац-крючок, всегда первый и единственный. Начинается с
  яркой сцены («Представьте муравья...», «Загляните в гнездо...»). В конце лида -
  обещание того, что будет дальше («а в конце покажем, как наблюдать дома»).
- **heading** `{ level: 2 }` - подзаголовок раздела. H1 не пишем, он берётся из
  `title` в hero. Все заголовки в теле - только `level: 2`.
- **paragraph** - 3-5 предложений, одна мысль на абзац.
- **image** `{ src, alt, caption }` - одиночное фото. CSS кадрирует его под 16:10,
  поэтому подойдёт любая ориентация.
- **row** `{ images: [двух] }` - два фото рядом. Показываются **целиком, без
  обрезки**, поэтому оба фото должны быть **похожей ориентации** (оба
  горизонтальные или оба вертикальные), иначе ряд выйдет разной высоты.
- **clip** `{ src, alt, caption }` - локальное видео как «живая гифка» (автоплей,
  без звука, по кругу; клик = зум, как у фото). `src = "/videos/<file>.mp4"` из
  `public/videos`. Ставить вместо `image`, когда есть короткий ролик. Тяжёлые
  файлы предварительно сжать.
- **deflist** `{ items: [{ q, a }] }` - список «термин - описание» для ролей, каст,
  фактов. **Не дублировать соседний абзац** (в 402 такой дубль убирали).
- **callout** `{ variant: "note", title, text }` - любопытный факт. `title` всегда
  «Знаете ли вы?».
- **quote** `{ text, author: "GoodAntShop" }` - короткая ударная мысль-девиз.
  `author` всегда «GoodAntShop».
- **keytakeaways** `{ title, items[] }` - 4-6 коротких пунктов-итогов. `title` -
  фраза-крючок («Почему это затягивает», «Коротко о мессорах»), не сухое «Итоги».
- **cta** `{ text, buttonLabel, to }` - призыв в конце. Тон: тёплое приглашение +
  фирменное обещание «мы поддержим вас на старте и подскажем каждый шаг». `to` ->
  `/ants`, `/formicariums` или карточка вида.
- **faq** `[{ q, a }]` - 2-3 вопроса-ответа (это поле верхнего уровня, отдельно от
  `content`, нужно для SEO). В ответах - внутренние ссылки.

## 3. Ритм статьи

- Чередовать текст и медиа: `heading -> paragraph -> (image | row | clip)`. Не
  ставить два медиа-блока подряд без текста между ними.
- Медиа распределять **равномерно по всей длине**, а не кучей в начале. После
  `keytakeaways` до конца - только текст и CTA, без фото.
- Эталонный каркас 401 и 402:
  `lead -> H2+para -> media -> H2+para -> media -> callout -> H2+para -> media ->
  quote -> H2+para (со ссылкой-CTA) -> keytakeaways -> cta -> faq`.
- Объём: ~9-12 блоков `content` + 2-3 `faq`, `readingTime` ~7.

## 4. Голос и приёмы

- Тёплый научпоп для любопытного новичка. Обращение на «вы» или безлично,
  дружелюбно, без канцелярита.
- Держать **одну сквозную аналогию с людьми** через весь пост: колония как
  «механизм / винтики / город / сверхорганизм» (401), муравьи как «крестьяне /
  ферма» (402). Аналогия связывает текст в целое.
- Конкретные образы вместо абстракций: «живая кладовая», «семя в несколько раз
  тяжелее рабочего», «хозяйство размером с ладонь».
- Короткие-средние предложения, активный залог. Абзац заканчивать запоминающейся
  строкой.
- Бренд-мотивы, консистентные между постами: **матка НЕ командует**; камеры делят
  с умом (**сухие - под зерно, влажные - под расплод**); «муравьиный хлеб»; колония
  тихая, чистая, компактная; наблюдать можно дома и годами.

## 5. Жёсткие правила набора (не нарушать)

- **Никаких длинных тире `—` и `–`.** Только « - » (пробел-дефис-пробел) в роли
  тире. Дефис внутри слова (кто-то, из-за, муравей-жнец) остаётся.
- **Без двоеточий** в тексте абзацев и подписей. Перечисление вводить через « - »
  или отдельным предложением.
- Спец-термины и «очеловеченные» слова - в ёлочки « »: «сверхорганизм»,
  «муравьиный хлеб», «скот», «касты», «охота».
- Внутренние ссылки - markdown `[текст](/путь)`: `/ants`, `/formicariums`,
  `/ants/<slug>`, `/about`. Внешних ссылок в теле нет.
- Без эмодзи в теле поста.

## 6. SEO

- `title` - выгода или метафора с именем сущности, не просто ключи. Паттерн:
  «<Сущность> - <образная выгода>». Одна мысль, которую **не повторяют** дословно
  excerpt и lead.
- `seoTitle` - «<крючок с ключом> | GoodAntShop», ~55-60 символов.
- `seoDescription` - 1-2 предложения: перечислить конкретные темы поста + аудитория
  или выгода в конце («Гид для новичков», «лучший вид для новичка»). ~150-160
  символов.
- `excerpt` - 2 предложения: интрига + что внутри. **Не дублировать** дословно
  `title` и lead (частая ошибка - title, excerpt и первый абзац про одну мысль).
- Один H1 (hero из `title`), дальше только H2. Ключ вида - в `title`, первом
  абзаце, alt обложки и faq.
- `cover` 1200×630, `alt` описательный и локализованный.
- Кросс-линковка: связать новый пост со старыми через `relatedPostIds` **в обе
  стороны**; в тексте - ссылки на каталог.

## 7. Чек-лист перед публикацией

- [ ] `title`, `excerpt` и первый абзац - три разные мысли, без дословных повторов.
- [ ] Нет `—` и `–`; нет двоеточий в тексте; термины в « ».
- [ ] Медиа чередуются с текстом и распределены равномерно; в `row` фото одной
      ориентации; в конце поста - только текст.
- [ ] Ни один `deflist` / `keytakeaways` не дублирует соседний абзац.
- [ ] `callout` = «Знаете ли вы?», `quote.author` = «GoodAntShop», CTA с фирменным
      обещанием поддержки.
- [ ] Биология проверена (матка не главная; мессор не охотник, но падаль ест;
      касты и размер заданы от рождения).
- [ ] Пост добавлен в `blogPostsData.js`, `relatedPostIds` проставлены в обе
      стороны, slug добавлен в `public/sitemap.xml` (ru/ro/en).
- [ ] `npm run build` проходит без ошибок; рендер проверен.

## 8. Похожи ли посты 401 и 402?

Да, стиль единый. Совпадает: схема объекта, набор и порядок блоков, крючок в лиде,
ёлочки « », запрет длинных тире, бренд-мотивы (матка не командует; сухие и влажные
камеры; «муравьиный хлеб»), паттерн `title`, «Знаете ли вы?», `quote` от
GoodAntShop, CTA с обещанием поддержки, блок FAQ.

Отличия осознанные и не ломают единство:

- 401 - широкий «манифест» (`category: "beginners"`, все три языка, несколько
  метафор сразу).
- 402 - про конкретный вид (`category: "species"`, пока ru-only, добавлен блок
  `clip`, одна сквозная «крестьянская» метафора вместо нескольких).

Посты перелинкованы друг на друга через `relatedPostIds` (401 ↔ 402).
